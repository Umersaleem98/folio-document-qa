## About

I build web applications that connect practical user needs with dependable backend systems and clear interfaces.

My recent project, Folio, is an AI-powered document Q&A application built with FastAPI, React, TypeScript, MySQL, and ChromaDB. It processes PDFs, retrieves relevant excerpts, and presents document-based answers with page citations. I implemented authentication, document ownership checks, administrative controls, and backend-enforced chat expiry after 24 hours of inactivity.

The project combines local Ollama embeddings with configurable hosted chat through Groq. Building it strengthened my understanding of retrieval quality, evidence validation, API integration, and application security.

I’m interested in full-stack development, backend engineering, and practical applications of retrieval-augmented generation.

Explore Folio: https://github.com/Umersaleem98/folio-document-qa
